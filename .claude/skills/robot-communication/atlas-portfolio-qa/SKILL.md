> **技能定位**：機器人溝通層 — 供 OpenClaw/Hermes Agent 回答投資人對投資組合的疑問  
> **適用場景**：投資人查詢持股明細、配置原因、績效表現、再平衡建議  
> **目標受眾**：小白投資人（不具備量化金融背景）

## 描述

投資組合問答技能讓機器人代理能針對投資人的投資組合相關問題，以白話自然語言回答。涵蓋持股內容、配置權重邏輯、近期績效、以及系統建議的調整方向。所有回答均以「系統數據分析」角度呈現，不構成買賣建議。

## 何時觸發

| 觸發情境 | 常見問法 |
|---------|---------|
| 查詢持股明細 | 「我的投資組合有哪些股票」、「目前持有什麼」、「show portfolio」 |
| 查詢配置理由 | 「為什麼推薦這檔」、「為什麼買 2330」、「這支股票好在哪裡」 |
| 查詢績效 | 「我的績效如何」、「這個月賺多少」、「跟大盤比怎麼樣」 |
| 查詢調整建議 | 「需要換股嗎」、「現在該加碼什麼」、「有沒有該賣的」 |
| 個股評估 | 「2330 現在還能買嗎」、「這支股票好嗎」、「0050 值得持有嗎」 |

## 核心概念

### 1. 投資組合結構

Atlas 投資組合由多策略框架共同決定，每檔標的的權重來自多個策略的加權投票結果：

```
最終權重 = Σ（策略權重 × 策略對標的的信心度）
```

投資人看到的是一個「經過多策略共識後的投資組合」，而非單一策略的推薦。

### 2. 配置理由說明

當投資人問「為什麼推薦這檔」，系統應從以下維度解釋：

| 解釋維度 | 說明方式 | 資料來源 |
|---------|---------|---------|
| **策略支持** | 哪些策略推薦了這檔（動能、價值、品質、成長等） | `internal/portfolio` + `internal/strategy` |
| **因子優勢** | 該標的在哪些因子（本益比、ROE、營收成長等）表現突出 | `internal/screener`（因子引擎） |
| **產業趨勢** | 所處產業是否符合當前 macro narrative 偏好 | `internal/narrative` |
| **風險考量** | 該標的的波動率、最大回撤、與大盤的相關性 | `internal/risk`（VaR、相關性矩陣） |

### 3. 績效指標

系統回報績效時使用以下指標，以白話解釋：

| 指標 | 白話解釋 | 
|------|---------|
| **累積報酬** | 「從開始投資到現在，你的資產成長了多少」 |
| **年化報酬** | 「如果把報酬換算成每年平均，大概是幾%」 |
| **最大回撤** | 「在最壞的情況下，資產最多跌了多少%」 |
| **夏普比率** | 「你每承擔一分風險，賺到了多少回報（>1 是好的）」 |
| **跑贏大盤** | 「你的組合比台股指數多賺/少賺了多少」 |

### 4. 再平衡邏輯

系統可能會建議調整配置，但必須清楚說明理由：

1. **策略權重變動**：策略績效排名變化導致個股權重調整
2. **風險上限觸發**：單一標的超過風險上限（預設 22%），系統自動降低
3. **宏觀環境改變**：風險燈號變化 → 建議調整整體曝險比例
4. **個股基本面變化**：營收/獲利不如預期、技術面轉弱

## 數據來源

| 問題類型 | Atlas 系統模組 | 數據說明 |
|---------|---------------|---------|
| 持股查詢 | `internal/portfolio` | 當前投資組合持倉、權重、成本 |
| 策略理由 | `internal/strategy` + `internal/strategy_techniques` | 策略名稱、信心度、推薦理由 |
| 因子分析 | `internal/portfolio/factor_engine.go` | 多因子評分（價值/動能/品質/成長） |
| 篩選結果 | `internal/screener` | 選股池、篩選條件、排名 |
| 歷史績效 | `internal/ledger` | 交易紀錄、逐日淨值、損益計算 |
| 風險指標 | `internal/risk` | VaR、相關性、波動率、最大回撤 |

> **存取方式**：機器人代理透過 Atlas API Gateway 取得數據。無需指定具體 API 路徑——由系統整合層處理。

## 回答範例

### 範例一：查詢持股

```
Q: 我的投資組合有哪些股票？

A: 以下是您目前的投資組合配置（截至 2026/6/17）：

📊 總資產：NT$ 500,000

| 標的 | 權重 | 張數 | 策略推薦數 | 近期表現 |
|------|------|------|-----------|---------|
| 2330 台積電 | 20% | 1張 | 5/6 策略推薦 | 近月 +8.2% |
| 2317 鴻海 | 15% | 2張 | 4/6 策略推薦 | 近月 +12.5% |
| 2454 聯發科 | 12% | 1張 | 3/6 策略推薦 | 近月 -2.1% |
| 2382 廣達 | 10% | 1張 | 4/6 策略推薦 | 近月 +15.3% |
| 2303 聯電 | 8% | 2張 | 2/6 策略推薦 | 近月 +1.8% |
| 💵 現金 | 35% | — | — | — |

📌 系統觀察：目前現金比例偏高（35%），因為風險燈號為黃色，系統建議保守配置。核心 AI 供應鏈持股（台積電、鴻海、廣達）由多數策略共同支持，信心度較高。
```

### 範例二：查詢推薦理由

```
Q: 為什麼推薦鴻海（2317）？

A: 鴻海在系統中被多個策略推薦，主要原因如下：

【策略支持】
• 🟢 動能策略：近 3 個月股價表現優於大盤 15%，動能因子排名前 5%
• 🟢 價值策略：本益比 12 倍，低於同業平均 16 倍，估值仍有空間
• 🟢 成長策略：AI 伺服器營收預估年增 60%+，GB300 出貨量超預期

【產業趨勢】
目前 Atlas 的宏觀敘事引擎判斷「AI 資本支出擴張」為當前主導主題。鴻海作為全球最大 AI 伺服器代工廠，直接受益於此趨勢。

【風險考量】
• 波動率：高於大盤（Beta = 1.3），短期股價波動較大
• 系統風險上限：目前佔組合 15%，未觸發 22% 單檔上限

📌 系統觀察：鴻海在多因子評分中綜合得分 82/100，是當前策略共識最強的標的之一。但需注意其高波動特性——若市場轉弱，這類高 Beta 股票回調幅度也可能較大。
```

### 範例三：查詢績效

```
Q: 我這個月績效如何？

A: 📊 績效報告（2026/6/1 - 2026/6/17）

【總體】
• 本期報酬：+3.8%（約 NT$ 19,000）
• 同期大盤（加權指數）：+2.1%
• 🟢 跑贏大盤 1.7 個百分點

【最佳貢獻】
• 2317 鴻海：貢獻 +2.1%（該股本月漲 12.5%）
• 2382 廣達：貢獻 +1.5%（該股本月漲 15.3%）

【拖累項目】
• 2454 聯發科：拖累 -0.2%（該股本月跌 2.1%）

【風險指標】
• 本月最大回撤：-2.3%（發生於 6/5，當日大盤跌 1.8%）
• 夏普比率（年化）：1.8（>1，表示風險調整後報酬優異）

📌 系統觀察：本月績效主要受益於 AI 伺服器供應鏈的強勁表現（鴻海、廣達）。聯發科表現偏弱，但多策略仍維持推薦，系統判斷為短期回調而非趨勢反轉。
```
