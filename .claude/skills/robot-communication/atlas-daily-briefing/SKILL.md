> **技能定位**：機器人溝通層 — 供 OpenClaw/Hermes Agent 定時觸發，向零售投資人推送每日市場摘要  
> **適用場景**：開盤前/收盤後排程推送、投資人主動查詢「今日市場如何」  
> **目標受眾**：小白投資人（不具備量化金融背景）

## 描述

每日投資摘要是一個**機器人排程技能**，系統每天自動生成一份繁體中文市場摘要，內容涵蓋：
- 當前市場狀態（多/空/盤整，來自 regime 偵測）
- 風險等級訊號（綠/黃/橙/紅四級 + 建議曝險比例）
- 本日推薦觀察標的（來自投資組合 top picks）
- 關鍵宏觀事件摘要（來自六大維度敘事引擎）

## 何時觸發

機器人代理在以下情況啟用此技能：

| 觸發情境 | 觸發方式 | 觸發詞 |
|---------|---------|--------|
| 排程推送 | 系統 Cron：每日 08:30 開盤前自動生成 | 無需觸發詞 |
| 投資人查詢 | 使用者主動發問 | 「今日市場如何」、「今天適合進場嗎」、「每日摘要」、「daily briefing」、「今天大盤怎麼樣」、「目前市場狀態」 |
| 收盤回顧 | 排程或使用者查詢 | 「今天收盤戰報」、「收盤回顧」、「今天股市總結」 |

## 核心概念

### 1. 市場狀態判斷（Regime Detection）

Atlas 透過 `internal/janus` 模組的雙面神機制判斷當前市場處於何種狀態：

| 市場狀態 | 特徵 | 系統建議 |
|---------|------|---------|
| **牛市（Risk-On）** | 指數站上所有均線、VIX 低、法人買超 | 維持正常配置，持股可偏高 |
| **熊市（Risk-Off）** | 指數跌破關鍵支撐、VIX > 25、法人賣超 | 提高現金比例，減少持股 |
| **盤整（Neutral）** | 指數在均線間震盪、方向不明 | 控制部位上限，等待方向確立 |
| **高波動（High Vol）** | 單日振幅 > 2%、VIX 急升 | 降低單檔上限，增加避險配置 |
| **轉換期（Transition）** | 市場方向正在改變 | 逐步調整配置，分批進出 |

### 2. 風險等級燈號

基於 `internal/risk` 模組的四層風險架構，每日摘要會呈現當前風險燈號：

```
🟢 綠色（正常）：無重大風險信號 → 建議曝險 80-100%
🟡 黃色（警戒）：單一風險信號 → 建議曝險 60-80%
🟠 橙色（危險）：雙重風險信號 → 建議曝險 40-60%
🔴 紅色（緊急）：系統性風險 → 建議曝險 < 40%
```

> **注意**：AI 結構性趨勢可能觸發豁免條件（如台積電營收 YoY > 50%），即使宏觀風險為橙色，核心 AI 持股可能不觸發回撤。

### 3. 本日推薦觀察標的（Top Picks）

來自 `internal/portfolio` 模組中由多策略權重加權後排名最高的 3-5 檔標的，包含：
- 標的名稱與代碼
- 策略支持理由（哪個策略推薦、信心度）
- 近 5 日表現（漲跌幅）

### 4. 關鍵宏觀事件

來自 `internal/narrative` 模組的六大維度敘事引擎（美元、美債、日圓、匯率、商品、地緣政治），以白話摘要呈現當日最關鍵的 2-3 個宏觀事件及其對台股的可能影響。

## 數據來源

| 摘要項目 | Atlas 系統模組 | 數據說明 |
|---------|---------------|---------|
| 市場狀態 | `internal/janus` | Regime 偵測（牛市/熊市/盤整/高波動/轉換期） |
| 風險等級 | `internal/risk` | RiskManager 輸出的四級風險燈號與建議曝險比例 |
| 推薦標的 | `internal/portfolio` | 多策略加權排名、top picks 清單 |
| 宏觀事件 | `internal/narrative` | 六大維度敘事引擎、外資出逃機率、資金流向推導 |
| 指數表現 | `internal/marketdata` | 加權指數、櫃買指數、電子/金融/傳產指數 |

> **存取方式**：機器人代理透過 Atlas API Gateway（`internal/apigateway`）統一取得上述模組數據，實際端點由系統整合層定義。
> **Wave 9 觀測**：每日摘要可能包含來自 Wave 9 可觀測性的 `EventIngestionLagSpike` 警報。

## 回答範例

### 範例一：投資人查詢「今日市場如何」

```
📊 2026年6月17日 開盤前市場摘要

【市場狀態】🟢 牛市（Risk-On）
目前加權指數站上所有主要均線（5/10/20/60日），VIX 處於 16.5 低位，外資連續 5 日買超，市場情緒偏樂觀。

【風險燈號】🟢 綠色 — 建議曝險 80-100%
目前無重大風險信號。美元利率穩定、日圓未見急升、地緣政治無新增威脅。
唯一的觀察點是美債 10Y 收益率近期緩升至 4.35%，若持續上升可能壓縮高估值科技股。

【本日觀察標的】
1. 2330 台積電 — 多策略共識看好（信心度 85%），近5日 +3.2%
2. 2317 鴻海 — AI 動能因子推薦（信心度 78%），近5日 +5.1%
3. 2454 聯發科 — 價值+品質雙因子支持（信心度 72%），近5日 -0.8%

【宏觀焦點】
• 美債 10Y 收益率升至 4.35%：需注意若突破 4.5%，科技股估值可能受壓
• Fed 主席將於今晚發表談話：市場預期 9 月降息機率 65%，關注措辭變化
• 外資動向：連續 5 日買超共 280 億，短線資金面偏多

📌 系統觀察：整體市場偏多，但美債收益率上行是潛在風險。建議維持正常配置，密切關注今晚 Fed 談話。
```

### 範例二：排程推動的收盤回顧

```
📊 2026年6月17日 收盤戰報

【指數表現】
加權指數：23,450（+1.2%），成交量 3,200 億
電子指數：+1.8%，金融指數：+0.3%，傳產指數：-0.2%

【今日風險變化】
風險燈號維持 🟢 綠色，無變化。
外資今日買超 85 億，投信買超 12 億，自營商賣超 5 億。

【今日最強標的】
• 2330 台積電：+3.5%（AI 資本支出上調 + 外資加碼）
• 2317 鴻海：+6.2%（伺服器出貨量創新高）
• 2382 廣達：+4.1%（AI 伺服器訂單能見度到 2027）

【明日關注重點】
• 今晚 Fed 談話後的市場反應
• 2330 台積電 ADR 溢價變化
• 外資期貨淨部位（今日 +2,300 口）

📌 系統觀察：台股今日量價齊揚，AI 族群持續領漲。若今晚 Fed 偏鴿，明日有機會挑戰年內新高。
```
