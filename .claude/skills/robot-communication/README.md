# Robot Communication Skills — 機器人溝通專用技能

## 用途

本目錄下的技能專供 **OpenClaw / Hermes Agent** 使用，讓 AI 機器人能將 Atlas 系統的複雜投資數據轉化為零售投資人（小白投資人）可理解的自然語言回應。

## 技能清單

| 技能 | 目錄 | 說明 |
|------|------|------|
| 每日投資摘要 | `atlas-daily-briefing/` | 每日定時推送市場摘要，含風險等級、推薦配置、宏觀事件 |
| 投資組合問答 | `atlas-portfolio-qa/` | 回答投資人對其投資組合的持股、配置理由、績效查詢 |
| 策略解釋 | `atlas-strategy-explain/` | 將量化策略（因子選股、達爾文權重演化）用白話解釋給非技術投資人 |
| 風險狀態解讀 | `atlas-risk-status/` | 解讀當前風險燈號，提供可參考的行動方向 |

## 運作機制

這些技能**假設機器人代理已透過 Atlas API Gateway（`internal/apigateway`）取得對應模組的資料存取權限**。技能內僅引用 Atlas 模組名稱（如 `internal/narrative`、`internal/risk`），不指定具體 API 路徑——實際端點由機器人代理的系統整合層決定。

## 設計原則

1. **非投資建議**：所有回應以「系統分析」、「數據觀察」角度呈現，不提供買賣建議
2. **白話優先**：避免量化金融術語，將因子、VaR、回撤等概念轉化為日常語言
3. **數據驅動**：所有結論必須基於 Atlas 系統實際數據，不含主觀判斷
4. **風險優先**：在市場樂觀時主動揭露潛在風險

## 重要警告

**這些技能設定 `auto_load: false`，不會在一般 AI 編碼工作中自動載入。** 僅在明確處理投資人面向功能時手動啟用，以避免在程式開發過程中干擾編碼決策。
