> **技能定位**：機器人溝通層 — 供 OpenClaw/Hermes Agent 解讀當前風險狀態並提供投資人可理解的行動參考  
> **適用場景**：投資人詢問風險高低、進場時機、減碼時機  
> **重要提醒**：本技能提供的是「系統風險數據解讀」而非投資建議。所有回應以數據觀察角度呈現。

## 描述

Atlas 系統內部有完整的四層風險管理架構（詳見 `atlas-risk-management` 技能），但這些機制對一般投資人過於複雜。本技能教導機器人代理如何將風險數據轉化為「燈號 + 白話解釋 + 可參考的行動方向」，讓投資人在 30 秒內理解當前風險狀態。

## 何時觸發

| 觸發情境 | 常見問法 |
|---------|---------|
| 詢問風險等級 | 「現在風險高嗎」、「市場危險嗎」、「風險燈號是什麼」 |
| 詢問進場時機 | 「現在可以進場嗎」、「適合買股票嗎」、「現在是好的買點嗎」 |
| 詢問減碼時機 | 「需要賣股票嗎」、「該減碼了嗎」、「要先把錢拿回來嗎」 |
| 市場大跌時 | 「今天為什麼跌這麼多」、「會繼續跌嗎」、「要不要先出場」 |
| 詢問防護機制 | 「你們怎麼保護我的錢」、「跌到多少會賣」、「有停損嗎」 |

## 核心概念

### 1. 四層風險架構（參考 `atlas-risk-management`）

Atlas 在四個階段設置了風險閘門，就像飛機上的多重安全檢查：

| 層級 | 檢查點 | 白話解釋 |
|------|--------|---------|
| **Pre-Trade（交易前）** | 下單前檢查 | 「這筆交易值得做嗎？風險會不會太高？」 |
| **In-Trade（交易中）** | 價格觸發即時檢查 | 「股票跌到某個價位，系統自動減碼」 |
| **Post-Trade（交易後）** | 收盤後整體檢視 | 「今天結束後，整個組合還安全嗎？」 |
| **Portfolio（組合層）** | 整體風險檢視 | 「所有持股加在一起，風險會不會太集中？」 |

### 2. 風險燈號系統

系統根據宏觀環境與市場數據，動態產生四級風險燈號：

```
🟢 綠色（正常）                       🟡 黃色（警戒）
├─ 無重大風險信號                    ├─ 單一風險信號出現
├─ 建議曝險：80-100%                  ├─ 建議曝險：60-80%
├─ 單檔上限：22%                      ├─ 單檔上限：15%
├─ 現金保留：0-10%                    ├─ 現金保留：15-25%
└─ 代表時期：2023年AI牛市             └─ 代表時期：2024年（美元高利率但AI強勁）

🟠 橙色（危險）                       🔴 紅色（緊急）
├─ 雙重風險信號同時出現               ├─ 系統性風險
├─ 建議曝險：40-60%                    ├─ 建議曝險：< 40%
├─ 單檔上限：10%                       ├─ 強制減半或清倉
├─ 現金保留：30-50%                    ├─ 現金保留：50%+
└─ 代表時期：2025/4川普關稅威脅         └─ 代表時期：2022/2俄烏戰爭、2024/8 Carry Trade unwind
```

### 3. 風險豁免機制

有些情況下，即使宏觀風險偏高，系統也不會對特定標的觸發回撤：

```
豁免條件：
1. 核心 AI 標的（台積電、鴻海、廣達）
2. 台積電營收 YoY > 50%
3. AI 資本支出預期持續上調
4. 內資承接力道強（投信買超 > 外資賣超）

→ 系統判斷：結構性產業趨勢強到足以戰勝宏觀逆風
→ 行動：核心 AI 持股不觸發回撤，但非核心持股仍會按風險燈號調整
```

### 4. VaR（風險值）— 白話解釋

**VaR（Value at Risk，風險值）** 是一個衡量「最壞情況下會虧多少」的指標：

```
白話解釋：
「在正常市場情況下，你的投資組合在一天內虧損超過 X 元的機率低於 5%」

舉例：
組合價值 NT$ 500,000，VaR = 2%（= NT$ 10,000）
→ 表示在 95% 的情況下，一天內虧損不會超過 1 萬元
→ 但有 5% 的機率，虧損「可能」超過 1 萬元

VaR 越高 → 系統會自動降低持股上限或增加現金比例
```

### 5. 回撤保護（Drawdown Protection）

當投資組合從最高點下跌達到一定幅度時，系統會自動啟動保護：

| 回撤幅度 | 系統行動 | 白話解釋 |
|---------|---------|---------|
| **-10%** | 降低單檔上限至 15%、增加現金至 20% | 「組合跌了 10%，系統開始變得謹慎」 |
| **-15%** | 降低單檔上限至 10%、增加現金至 30% | 「跌幅擴大，進一步降低風險」 |
| **-20%** | 強制減半、現金 50%+ | 「觸發強制保護機制，先保本金要緊」 |

| 風險指標 | Atlas 系統模組 | 說明 |

| 風險燈號 | `internal/risk`（RiskManager） | 四級風險燈號、建議曝險比例、單檔上限 |

| 宏觀風險因子 | `internal/narrative` | 外資出逃機率、資金流向、六大維度風險信號 |
| 交易前後檢查 | `internal/risk`（pre_trade.go / post_trade.go） | 交易前風險閘門、交易後組合風險評估 |

> **存取方式**：機器人代理透過 Atlas API Gateway 取得數據。無需指定具體 API 路徑——由系統整合層處理。

## 回答範例

### 範例一：詢問風險燈號

```
Q: 現在風險高嗎？

A: 🟡 目前風險燈號：黃色（警戒）

【為什麼是黃色】
系統偵測到「美債 10Y 收益率上升至 4.35%」這一風險信號。當美債收益率接近 4.5% 時，通常會壓縮高估值科技股的評價空間，對台股（以科技股為主）構成壓力。

【目前的保護措施】
• 單一股票上限從 22% → 降至 15%（避免過度集中在某一檔）
• 現金保留從 10% → 提高至 15-25%（手上留更多現金）
• 整體持股比例：建議維持在 60-80%

【豁免情況】
雖然風險燈號為黃色，但系統判斷 AI 產業趨勢仍強勁：
• 台積電營收 YoY +45%，優於預期
• CSP 雲端大廠（Google、微軟、亞馬遜）AI 資本支出持續上調
→ 核心 AI 持股（2330 台積電、2317 鴻海、2382 廣達）不觸發強制回撤

📌 系統觀察：風險為黃色（警戒）而非綠色，表示市場有需要關注的風險。但 AI 產業基本面強勁，系統判斷目前不需要大幅減碼，只需適度提高現金比例即可。
```

### 範例二：大跌日的應對

```
Q: 今天為什麼跌這麼多？要不要先賣掉？

A: 今天加權指數跌幅 2.8%，以下是 Atlas 系統的分析：

【下跌原因】（來自 internal/narrative 模組）
• 主要觸發：Fed 官員鷹派發言，市場將 9 月降息機率從 65% 下調至 40%
• 外資今日賣超 120 億，為近 2 週最大單日賣超
• 美債 10Y 收益率急升至 4.42%（+7bp）
• 日圓未見異常波動，排除 Carry Trade unwind 風險

【風險燈號變化】
• 今日前：🟡 黃色
• 今日後：🟡 黃色（維持不變）
• VaR 從 2.0% 上升至 2.4%，仍在可控範圍
• 回撤監控：從高點回撤 -4.2%，尚未觸發任何保護閾值

【系統建議的方向性參考】
• 不急著賣：目前跌幅尚未觸發任何系統性保護機制
• 觀察點：若美債 10Y 在 3 個交易日內突破 4.5%，風險燈號可能升至 🟠 橙色
• 現金比例：目前 15%，若風險升至橙色，系統將自動提高至 30%

📌 系統觀察：今日下跌主要是 Fed 談話引發的短期情緒波動（非系統性風險）。目前風險燈號維持黃色，回撤幅度也未觸發保護機制。建議觀察接下來 2-3 天的美債收益率走勢——這是關鍵判斷指標。
```

### 範例三：詢問進場時機

```
Q: 現在適合進場嗎？

A: 🟡 目前的市場狀態與風險分析：

【市場狀態】牛市（Risk-On），但風險燈號為黃色
• 指數仍在所有主要均線之上
• 但美債收益率上行是潛在壓力

【風險收益評估】
• 好消息：AI 產業基本面強勁，台積電/鴻海營收持續超預期
• 需注意：美債收益率若突破 4.5%，可能引發短期回調

【系統數據參考】
• 外資期貨淨部位：+3,500 口（偏多）
• VIX：18.2（中等，非恐慌水準）
• 台股融資餘額：穩定，散戶未過度樂觀

📌 系統觀察：以數據角度看，當前市場「機會與風險並存」。若選擇進場，系統建議：
1. 分批進場（不要一次把資金用完）
2. 優先選擇 AI 核心標的（系統信心度最高）
3. 保留 15-25% 現金作為緩衝
4. 若美債 10Y 突破 4.5% → 暫停加碼，等待回調後再進場

（以上為系統數據分析，不構成買賣建議。投資決策請依個人風險承受能力自行判斷。）
```
