> **技能定位**：機器人溝通層 — 供 OpenClaw/Hermes Agent 將量化策略用白話解釋給投資人  
> **適用場景**：投資人想了解「為什麼這樣投資」、「策略邏輯是什麼」  
> **目標受眾**：小白投資人（不具備量化金融背景）

## 描述

Atlas 系統內部使用高度量化的投資策略（因子選股、達爾文權重演化、多策略投票機制），這些概念對一般投資人極難理解。本技能教導機器人代理如何將這些技術概念轉化為日常語言，讓投資人理解「系統為什麼這樣選股」以及「背後的邏輯是什麼」。

## 核心概念

### 1. 因子選股 — 用分數選股票

**白話解釋**：就像買房子要看地段、坪數、價格一樣，選股票也需要看幾個關鍵指標。這些指標在投資界稱為「因子」。

| 因子 | 白話解釋 | 舉例 |
|------|---------|------|
| **動能（Momentum）** | 「最近漲得好的，可能還會繼續漲」 | 過去 3-6 個月表現強勢的股票 |
| **價值（Value）** | 「用便宜的價格買到好東西」 | 本益比低於同業、股價淨值比偏低 |
| **品質（Quality）** | 「買體質好的公司，睡得安穩」 | ROE 高、負債低、現金流穩定 |
| **成長（Growth）** | 「買未來會長大的公司」 | 營收年增率 > 20%、獲利持續創新高 |
| **低波動（Low Vol）** | 「選比較穩的，不會暴漲暴跌」 | 過去一年波動率低的股票 |

**系統如何運作**：`internal/portfolio/factor_engine.go` 會對每檔股票打分數，綜合多個因子後產出一個「總分」，分數越高代表系統越看好。

### 2. 達爾文權重演化 —「好策略留下，爛策略淘汰」

**白話解釋**：Atlas 同時運行多個投資策略，就像一個「策略競賽」。每個月系統會檢查各策略的表現：
- 表現好的策略：增加它的「發言權」（權重變大）
- 表現差的策略：減少它的「發言權」（權重變小）
- 太差的策略：直接淘汰，換新策略上場

這就是「達爾文演化」的概念——適者生存。

```
初始：策略 A（權重 20%）、策略 B（20%）、策略 C（20%）、策略 D（20%）、策略 E（20%）
↓ 一個月後（演化）
策略 A 表現最好 → 權重 30% ↑
策略 C 表現最差 → 權重 10% ↓
策略 E 連續 3 個月墊底 → 淘汰，新策略 F 上場
```

### 3. 多策略投票機制

**白話解釋**：Atlas 不會只聽一個策略的意見。系統中有多個策略同時對每檔股票「投票」：

- 5 個策略都說「買 2330 台積電」→ 系統信心度 90%+，配置 20%
- 只有 2 個策略說「買 2303 聯電」→ 系統信心度 40%，配置 8%
- 0 個策略看好某檔 → 不納入投資組合

這就像請了 5 位投資顧問幫你看股票，綜合多數人的意見做決定。

### 4. 五層心法框架（L1-L5）

Atlas 的投資決策有五層思考（來自 `internal/strategy_techniques`），從全球宏觀到個股籌碼，層層把關：

| 層級 | 內容 | 白話解釋 |
|------|------|---------|
| **L1 全球流動性** | Fed 利率、美元走勢 | 「現在全世界資金是寬鬆還是緊縮？」 |
| **L2 外資行為** | 外資買賣超、法人動向 | 「外國大戶在買還是賣台股？」 |
| **L3 產業催化** | AI、半導體、油價 | 「現在什麼產業最熱門？」 |
| **L4 匯率籌碼** | 新台幣、融資水位 | 「台幣強弱、散戶是樂觀還是悲觀？」 |
| **L5 地緣政治** | 戰爭、關稅、兩岸 | 「有沒有打仗或貿易戰的風險？」 |

## 回答範例

### 範例一：解釋策略如何選股

```
Q: 你們的策略是怎麼選股票的？

A: 想像 Atlas 系統像一個「投資委員會」，裡面有 5 位不同的投資顧問（策略）。每位顧問都有自己的選股邏輯：

1️⃣ 動能型顧問：專挑「最近漲得猛的」，因為他相信強者恆強
2️⃣ 價值型顧問：專找「被低估的好公司」，像在特賣會挖寶
3️⃣ 品質型顧問：只看「體質好的公司」，ROE 高、負債低的他才放心
4️⃣ 成長型顧問：追蹤「營收獲利大增的公司」，不怕買貴只怕錯過
5️⃣ 低波動型顧問：偏好「穩穩的股票」，市場大跌時他選的股票也比較抗跌

每位顧問每天會對台股所有股票打分數。最後系統會綜合 5 位顧問的分數，選出得分最高的前 10-15 檔股票放進投資組合。

而且——如果某位顧問連續幾個月表現不好，系統會自動降低他的發言權，甚至換一位新顧問上場。這就是我們說的「達爾文演化」——好策略留下，爛策略淘汰。
```

### 範例二：解釋因子概念

```
Q: 什麼是動能因子？聽起來很複雜。

A: 「動能因子」簡單說就是：「最近漲得好的股票，短期內可能還會繼續漲。」

舉個生活例子：
如果一家餐廳最近天天排隊，你會不會覺得「這家這麼多人排，應該很好吃」？
股市也是類似的邏輯——如果一檔股票過去幾個月一直漲，代表背後可能有我們還不知道的好消息，資金持續湧入。

Atlas 系統的做法：
• 看過去 3 個月和 6 個月的漲幅
• 跟同產業的其他股票比較
• 分數越高 = 動能越強 = 系統越看好

❗ 但要注意：動能就像衝浪，浪大的時候很爽，但浪退的時候也可能跌很快。所以 Atlas 不會只用動能這一個指標，而是結合價值、品質、成長等其他因子綜合判斷。
```

### 範例三：解釋為何推薦某檔股票

```
Q: 為什麼系統推薦台積電（2330）？

A: 從 Atlas 多策略的視角來看：

【策略投票結果】
• 動能策略：✅ 推薦（近 3 個月漲幅領先大盤，動能分數 Top 3%）
• 價值策略：✅ 推薦（以 2027 年預估獲利看，本益比仍合理）
• 品質策略：✅ 推薦（ROE 25%+，負債極低，現金流充沛）
• 成長策略：✅ 推薦（AI 晶片需求催動營收成長 40%+）
• 低波動策略：⚠️ 未推薦（台積電波動偏高，不符合此策略風格）

5 個策略中有 4 個推薦 → 系統信心度 88% → 配置 20%（接近上限）

【簡單說】
系統看好台積電的核心原因是：AI 需求推動營收大幅成長，同時公司體質極佳。唯一的弱點是股價波動較大。綜合來看，多數策略認為「股價還有上漲空間，值得持有」。
```
