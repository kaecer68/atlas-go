# Lessons

Session-derived learnings that do not rise to the level of a recurring footgun but are worth preserving.

## Format

Name files `YYYY-MM-DD-<short-description>.md`.

```markdown
# Lesson Title

- **Date**: YYYY-MM-DD
- **Context**: what task was being performed
- **Trigger**: what event prompted the lesson

## What Happened

## What We Learned

## Action Items
```

Delete lessons that become outdated or are superseded by skills/rules.
