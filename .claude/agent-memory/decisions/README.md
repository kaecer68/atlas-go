# Decisions

Architecture and process decisions that should not be quietly reversed by future agents.

## Format

Name files `<topic>-decision.md` (no date prefix for active decisions; use date for retired/overridden decisions).

```markdown
# Decision Title

- **Date**: YYYY-MM-DD
- **Status**: active / superseded / retired
- **Superseded by**: link (if applicable)

## Context

## Decision

## Rationale

## Consequences

## References
```
