## 如何使用這個 Handoff

### 情境 A：回來繼續 W3
```
「上次我們做完了 W1/W2/W4，W3 在另一個 workspace 跑。
   看 /Users/kaecer/workspace/atlas/.omo/phase6/W3-decision-chain-v2.md
   如果有 /tmp/w3-report.md，拿來這裡繼續。」
```

### 情境 B：新 AI 接手，需要了解整體
```
「讀 /Users/kaecer/workspace/atlas/.omo/phase6/Master-Plan.md
   然後看 .omo/maps/architecture.md 了解目前架構。
   目前 main branch 是最新的，包含 W1/W2/W4 全部合併。
   W3 還在進行中。」
```

### 情境 C：需要跑系統地圖
```
cd /Users/kaecer/workspace/atlas
go run ./cmd/mapgen -map arch,routes,fe-be   # 快速（3s，不含 coverage）
go run ./cmd/mapgen -gen-all                   # 完整（含 coverage，60-100s）
cat .omo/maps/api-routes.md                    # 看所有 API routes
cat .omo/maps/module-completeness.md           # 看模組完成度
```

### 情境 D：需要跑模擬
```
go run ./cmd/atlas --simulate --date 2026-05-26 --verbose
# trace log → .omo/traces/sim-20260526.jsonl
# API → curl localhost:8080/api/traces/sim-latest
```

### 情境 E：需要查事件邏輯庫
```
curl localhost:8080/api/eventlogic/rules/active     # active rules
curl localhost:8080/api/eventlogic/stats             # stats
curl localhost:8080/api/eventlogic/rules/{id}/validate  # validate a rule
```
