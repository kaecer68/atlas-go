## Phase 6: Market Microstructure

### 目標
建立微觀結構信號，過濾低流動性標的，識別異常交易模式。

### 限制
- 無免費 L1/L2 數據（延續 v1.1 決策）
- 使用 OHLC + Volume 計算 proxy 指標

### 設計

#### 6.1 Proxy 指標計算

**檔案**: `internal/marketdata/microstructure_provider.go`

```go
type MicrostructureSnapshot struct {
    Symbol              string    `json:"symbol"`
    AsOf                time.Time `json:"as_of"`
    
    // 流動性指標
    LiquidityScore      float64   `json:"liquidity_score"`       // 0-100
    SpreadEstimate      float64   `json:"spread_estimate"`       // 估算價差（%）
    VolumeSurgeRatio    float64   `json:"volume_surge_ratio"`    // 成交量 / 20日均量
    
    // 波動性指標
    RealizedVolatility  float64   `json:"realized_volatility"`   // 5日實現波動率
    VolatilityRegime    string    `json:"volatility_regime"`     // "low" | "normal" | "high" | "extreme"
    
    // 微觀結構異常
    AbnormalVolume      bool      `json:"abnormal_volume"`       // 成交量 > 3倍均量
    PriceGapRisk        bool      `json:"price_gap_risk"`        // 高波動 + 低流動性
    
    // 綜合評級
    TradeabilityScore   float64   `json:"tradeability_score"`    // 0-100，綜合可交易性
}
```

**計算邏輯**:

1. **估算價差 (SpreadEstimate)**:
   ```
   spread = (High - Low) / Last * (1 / sqrt(Volume / AvgVolume20))
   ```
   原理：高波動 + 低成交量 = 高價差

2. **流動性分數 (LiquidityScore)**:
   ```
   volume_score = min(Volume / AvgVolume20 * 25, 50)
   price_score = max(0, 50 - SpreadEstimate * 1000)
   LiquidityScore = volume_score + price_score
   ```

3. **可交易性分數 (TradeabilityScore)**:
   ```
   TradeabilityScore = LiquidityScore * (1 - RealizedVolatility/2)
   ```
   高流動性 + 低波動 = 高可交易性

func (e *Engine) applyMicrostructureFilter(
    symbol string,
    criteria domain.ScreeningCriteria,
    microData map[string]marketdata.MicrostructureSnapshot,
) (bool, string) {
    snap, ok := microData[symbol]
    if !ok {
        return false, "缺少微觀結構數據"
    }
    
    if criteria.MinLiquidityScore != nil && snap.LiquidityScore < *criteria.MinLiquidityScore {
        return false, fmt.Sprintf("流動性分數過低: %.1f < %.1f", snap.LiquidityScore, *criteria.MinLiquidityScore)
    }
    
    if criteria.MaxSpreadEstimate != nil && snap.SpreadEstimate > *criteria.MaxSpreadEstimate {
        return false, fmt.Sprintf("估算價差過大: %.2f%% > %.2f%%", snap.SpreadEstimate*100, *criteria.MaxSpreadEstimate*100)
    }
    
    if criteria.ExcludeAbnormalVolume != nil && *criteria.ExcludeAbnormalVolume && snap.AbnormalVolume {
        return false, "成交量異常放大"
    }
    
    return true, ""
}
```

func (fe *FactorEngine) CalculateLiquidityScore(
    symbol string,
    micro marketdata.MicrostructureSnapshot,
) FactorScore {
    baseScore := micro.TradeabilityScore / 100.0 * 10.0  // 0-10
    
    // 流動性過低直接扣分
    if micro.LiquidityScore < 20 {
        baseScore = -5.0

    if micro.AbnormalVolume {
        baseScore -= 3.0

        Score:     math.Max(-10, math.Min(10, baseScore)),
        Weight:    fe.config.LiquidityWeight,
        Formula:   "tradeability_score * 0.1 + liquidity_penalty",
        RawInputs: map[string]float64{
            "liquidity_score": snap.LiquidityScore,
            "spread_estimate": snap.SpreadEstimate,
            "volume_surge":    snap.VolumeSurgeRatio,
        },
    }
}

func calculateMacroSimilarity(current, historical MacroSnapshot) float64 {
    factors := []string{"vix", "us_10y_yield", "usd_twd", "taiex_pe"}
    weights := map[string]float64{"vix": 0.3, "us_10y_yield": 0.2, "usd_twd": 0.3, "taiex_pe": 0.2}
    
    similarity := 0.0
    for _, f := range factors {

        similarity += weights[f] * max(0, 1-diff)
    }
    return similarity
}

func (kb *KnowledgeBase) calculateWeightedHitRate(theme string, expectation SeasonalExpectation) float64 {
    baseHitRate := hitRateForTheme(theme)
    
    // 預期差越大，歷史命中率參考價值越低（因為情境不同）
    // 預期差越小，歷史命中率越可靠
    reliability := 1.0 - expectation.SurprisePotential
    
    // 已反應的情境，命中率應該降低
    if expectation.AlreadyPricedIn {
        return baseHitRate * 0.5
    }
    
    return baseHitRate * (0.7 + 0.3*reliability)
}
```

#### 8.2 指數衰減權重

```go
func calculateExponentialWeights(days int, halfLife int) []float64 {
    weights := make([]float64, days)
    lambda := math.Ln2 / float64(halfLife)
    
    total := 0.0
    for i := 0; i < days; i++ {
        // 越近期的數據權重越高
        w := math.Exp(-lambda * float64(days-1-i))
        weights[i] = w
        total += w
    }
    
    // 正規化
    for i := range weights {
        weights[i] /= total
    }
    return weights
}

func (w *DarwinianAgentWeight) CalculateWeightedSharpe(returns []float64, weights []float64) float64 {
    if len(returns) != len(weights) {
        panic("returns and weights length mismatch")
    }
    
    weightedAvg := 0.0
    for i, r := range returns {
        weightedAvg += r * weights[i]
    }
    
    // 使用加權標準差
    weightedVar := 0.0
    for i, r := range returns {
        diff := r - weightedAvg
        weightedVar += weights[i] * diff * diff
    }
    
    if weightedVar == 0 {
        return 0
    }
    
    return weightedAvg / math.Sqrt(weightedVar)
}
```

#### 8.3 新 Agent 保護期

```go
func (m *DarwinianWeightManager) PerformDailyAdjustment(
    ctx context.Context,
    agentWeights []DarwinianAgentWeight,
    outcomes []domain.Outcome,
) ([]DarwinianAgentWeight, error) {
    
    for i := range agentWeights {
        aw := &agentWeights[i]
        
        // 檢查是否為新 agent（保護期內）
        if m.isNewAgent(aw) {
            // 固定權重，不調整
            aw.Weight = m.config.NewAgentFixedWeight
            continue
        }
        
        // 檢查冷卻期（最少調整間隔）
        if m.isInCooldown(aw) {
            continue
        }
        
        // 計算加權 Sharpe
        weights := calculateExponentialWeights(len(aw.DailyReturns), m.config.DecayHalfLifeDays)
        weightedSharpe := aw.CalculateWeightedSharpe(aw.DailyReturns, weights)
        aw.RollingSharpe = weightedSharpe
        
        // ... 現有分層調整邏輯 ...
        
        // 慣性因子：權重變化不會一步到位
        oldWeight := aw.Weight
        targetWeight := aw.Weight  // 經過分層調整後的目標權重
        aw.Weight = oldWeight + (targetWeight-oldWeight)*m.config.WeightMomentumFactor
        
        // 記錄最後調整時間
        aw.LastAdjustedAt = time.Now()
    }
    
    return agentWeights, nil
}

func (m *DarwinianWeightManager) isNewAgent(aw *DarwinianAgentWeight) bool {
    // 從首次交易日期計算
    firstSignalDate := aw.FirstSignalDate
    if firstSignalDate.IsZero() {
        return true
    }
    return time.Since(firstSignalDate).Hours() < float64(m.config.NewAgentProtectionDays*24)
}

func (m *DarwinianWeightManager) isInCooldown(aw *DarwinianAgentWeight) bool {
    if aw.LastAdjustedAt.IsZero() {
        return false
    }
    daysSinceLastAdjust := int(time.Since(aw.LastAdjustedAt).Hours() / 24)
    return daysSinceLastAdjust < m.config.MinAdjustmentInterval
}
```

### 完整資料流

```
Phase 5: Retail Sentiment
    TWSE API → RetailSentimentProvider → MacroDataSnapshot.RetailSentiment
                                        → NarrativeEvent (retail_frenzy/fear)
                                        → Dashboard API

Phase 6: Microstructure
    Quote (OHLCV) → MicrostructureProvider → MicrostructureSnapshot
                                          → Screener (流動性/價差/異常成交量過濾)
                                          → FactorEngine (LiquidityFactor)

Phase 7: Seasonal Refinement
    Ledger (歷史數據) → SeasonalAnalyzer → SeasonalExpectation
                                      → detectSeasonalEvent (預期差驅動)
                                      → 動態命中率調整

Phase 8: Darwinian Optimization
    Outcomes → DarwinianWeightManager (60日窗口 + 指數衰減)
           → 新Agent保護期
           → 冷卻期機制
           → 慣性因子
```

### 與現有系統整合點

| 模組 | 整合方式 |
|------|---------|
| `marketdata` | 新增 2 個 Provider（RetailSentimentProvider, MicrostructureProvider） |
| `narrative` | 新增 3 個事件偵測函數 + 1 個分析器 |
| `screener` | 新增 4 個篩選條件 |
| `portfolio` | 擴展 FactorEngine + 重寫 DarwinianWeightManager |
| `domain` | 新增 2 個結構（RetailSentimentSnapshot, MicrostructureSnapshot） |
| `monitoring` | 新增 1 個 Dashboard endpoint |

## 風險與緩解

| 風險 | 可能性 | 影響 | 緩解 |
|------|--------|------|------|
| TWSE API 速率限制 | 中 | 高 | 實現指數退避重試 + 本地快取 |
| 融資餘額數據延遲 | 高 | 中 | 使用盤後數據（T+0），非即時也可接受 |
| 微觀結構 proxy 不準確 | 高 | 中 | 標記為 proxy，避免過度依賴 |
| 歷史數據不足（< 10 年） | 低 | 中 | 縮短 lookback 至 5 年 |
| 新 Agent 保護期過長 | 低 | 低 | 配置化（預設 30 天，可調） |
| 權重冷卻期導致反應遲鈍 | 低 | 中 | 緊急情況下可繞過冷卻期 |

## 效能考量

- **融資餘額抓取**: 每日一次，非即時，不影響盤中效能
- **微觀結構計算**: 基於 OHLCV，計算量小，可即時完成
- **季節性分析**: 從 ledger 讀取，可預先計算並快取
- **權重調整**: 每日一次，與現有邏輯相同
