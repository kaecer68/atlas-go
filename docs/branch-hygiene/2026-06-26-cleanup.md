## 盤查方法（可重現）

對每個落後 main > 5 commits 的 branch：

1. **取獨特 commit**：`git log main..<branch> --oneline`（branch 不在 main
   的 commits）
2. **驗證已在 main**：取每個 commit 的 message subject，用
   `git log main --grep="<keyword>"` 檢查 squash merge 後用不同 SHA 但
   同/近 message 落地的工作
3. **驗證檔案路徑**：若 grep 未命中，再 `git show --stat` 看 commit
   修改的檔案，檢查該檔案是否已被 Wave 10+ PR（如 #716）併入

```bash

# worktree prune
```
