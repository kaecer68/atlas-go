## A04 — `/api/regime/history` 404

| 欄位 | 內容 |
|------|------|
| 問題 | MCP `regime_get_history` 可成功，但 HTTP `GET /api/regime/history?days=5` 回 404 |

| 檔案 | `internal/monitoring/api/pipeline/handlers.go` |

## A05 — snapshot 未持久化 geopolitical 分量

| 欄位 | 內容 |
|------|------|
| 問題 | `data/state/macro/*.json` 缺少 geo intensity，重建歷史壓力分數時 geo=0 |
| 根因 | `MacroIngestor.Ingest` 只接受 macro snapshot，geo 由 `DashboardAPI.IngestAndUpdateMacro` 另外取得後才餵給 engine；snapshot 寫檔時沒帶 geo |
| 檔案 | `internal/marketdata/macro_provider.go`、`internal/narrative/ingestor.go`、`internal/monitoring/dashboard_api.go` |
| 驗收 | 新 snapshot JSON 含 `geopolitical_intensity`；`IngestAndUpdateMacro` 觸發的 macro ingestion 會把 geo 寫入 dated + latest snapshot；舊 snapshot（無此欄位）可 backward 相容 |
| Migrate 策略 | 新欄位 `omitempty`；舊檔案視為 0（即現狀）；未來回填或標記 `geo_missing=true` 不在本次 scope |
