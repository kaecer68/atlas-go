## 一、問題發現總結

### 1.1 稽核背景

Atlas-Go 前端採用單一 HTML 檔案（`index.html`，2402 行）的 SPA 架構，服務內部研究人員的投資決策需求。經 6-Pillar Visual Audit 稽核，原始評分為 **2.8/4**（Fair to Good），存在 11 項優先修復項目。

### 1.2 問題分類統計

| 嚴重度 | 數量 | 說明 |
|--------|------|------|
| 🔴 Blocking | 3 | 鍵盤導航失效、對比度不足、硬編碼色彩 |
| 🟡 High Impact | 4 | 表格溢位、按鈕反饋缺失、Modal 無障礙、間距不一致 |
| 🟢 Medium Impact | 4 | 內聯樣式、載入動畫、字階系統、色彩統一 |

### 1.3 核心問題詳情

#### A. 無障礙缺陷（最嚴重）
- **無焦點樣式**: 完全沒有 `:focus-visible`，鍵盤使用者無法導航
- **Modal 無障礙**: 缺少 `aria-modal`、`role="dialog"`、Escape 鍵關閉
- **對比度失敗**: `--muted: #8e99ab` 僅 4.2:1，低於 WCAG AA 的 4.5:1

#### B. 設計系統崩壞
- **硬編碼色彩**: 主按鈕 `#1f6feb`、危險按鈕 `#da3633`、factorBar 色彩等未使用 CSS 變數
- **內聯樣式氾濫**: 約 120+ 個 `style=` 屬性，維護困難
- **無系統化尺度**: 無間距變數、無字階變數、無字重變數

#### C. 互動體驗不足
- **按鈕無按下感**: 缺少 `:active` 狀態
- **載入無動畫**: 靜態「載入中…」文字，無旋轉圖示
- **通知關閉無反饋**: 關閉按鈕僅有 `cursor: pointer`，無色彩變化
