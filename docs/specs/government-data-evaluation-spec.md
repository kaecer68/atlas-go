# BK-14：八大行庫第三方資料採購評估

> **評估日期**：2026-07-19
> **評估對象**：CMoney、Goodinfo（及替代方案）
> **目的**：評估購買「八大行庫買賣超」第三方整理資料的商業可行性
> **關聯**：`docs/specs/government-force-proxy-spec.md` §2 選項 B

---

## 1. 資料來源概述

### CMoney
- **產品名稱**：法人買賣超彙整表（含八大行庫分項）
- **資料粒度**：每日／個股／八大行庫合計淨買賣超（元）
- **更新頻率**：T+1（盤後約 17:00）
- **歷史長度**：通常提供 5-10 年
- **交付方式**：API（CMoney DataFeed）或 CSV 下載
- **授權模式**：商用 API，年約制，通常 6-12 萬 NTD/年（含法人模組）
- **口徑說明**：CMoney 使用證交所每日分點資料自行加總；口徑為「公股行庫旗下券商分點」，與 `government-force-proxy.md` §1 定義高度一致

### Goodinfo（台灣股市資訊網）
- **產品名稱**：八大行庫買賣超（免費公開）
- **資料粒度**：每日／全市場合計淨買賣超（元），不可拆個股
- **更新頻率**：T+1
- **交付方式**：僅網頁呈現，無結構化 API，需自行爬取
- **授權**：免費公開但無正式 API 使用條款；頻繁爬取可能被擋
- **口徑說明**：Goodinfo 自行整理，口徑未公開，無法驗證

### 替代方案：直接使用證交所分點資料（BK-13）
- **資料來源**：證交所「各股分點買賣超日報表」
- **優點**：權威第一方、可自行定義官股券商清單、無需授權費
- **缺點**：需自建爬蟲或解析 HTML（非 OpenAPI），開發成本較高
- **狀態**：BK-13 backlog，尚未實作

## 2. 比較矩陣

| 維度 | CMoney API | Goodinfo | 自建（BK-13） |
|------|-----------|----------|--------------|
| 權威性 | 中（第三方加工，但引用 TWSE 源） | 低（口徑不透明） | 高（直讀 TWSE 源） |
| 個股粒度 | ✅ 可拆個股 | ❌ 僅全市場合計 | ✅ 可拆個股/分點 |
| 資料格式 | JSON API | HTML（需爬） | 依實作 |
| 歷史資料 | 5-10 年（付費） | 有限 | 逐日累積 |
| 年費 | 6-12 萬 NTD | 免費（但風險） | 僅開發成本 |
| 合規風險 | 商業授權明確 | 灰色地帶（無 API TOS） | 合規（公開資料） |
| 開發成本 | 低（1-2 天接 API） | 中（爬蟲維護） | 高（HTML 解析＋排程維護） |

## 3. 資料品質風險

### CMoney
- ✅ 產業標準，多數投顧/媒體採用
- ⚠️ 口徑與本系統定義可能有微小差異（例如是否納入元大證券）；需求確認時需對齊
- ⚠️ 年約制，續約斷層會導致空白期

### Goodinfo
- ⚠️ 僅全市場合計，無法拆個股 → 對 `government` force 有值但對個股籌碼分析**無助益**
- ⚠️ 爬蟲結構易被擋，不適合排程化
- ❌ 口徑不透明，無法與本系統七維分類學對齊

---

## 4. 建議

### 短期（當前最適）
**不採購**。目前 `government` force 採用 v1「操作員匯入」模式（`government-force-proxy.md` §3），成本接近零，滿足「有這個 force 但不給假訊號」的誠實需求。官股 force 的 `data_available=false` 標記已正確反映此狀態。

### 中期（6-12 個月）
**CMoney API 採購**（優先於 Goodinfo）。若業主認為官股訊號對散戶確實有資訊價值：
- 年費 6-12 萬，可與既有法人模組打包議價
- 對接成本低（1-2 天）
- 個股粒度可直接補 `stock_get_chips` 的官股欄位
- 口徑需在採購前與 CMoney 確認是否與本系統官股定義一致（8 家公股，不含元大）

### 長期（最佳路徑）
**BK-13 自建證交所分點加總通道**。這是成本最低、口徑最可控的終局方案：
- 零授權費
- 第一方資料，不受第三方變更影響
- 可自行定義官股券商清單
- 開發成本約 1-2 週（HTML 解析器 + 每日排程 + 歷史回填）

---

## 5. 對 system 的影響

無論採哪條路徑，一旦有了穩定日頻資料源：
1. `government` force 從 `data_available=false` → `true`
2. 共振模型可納入官股（subject force 之一，依 E05 定義）
3. 需累積 ≥30 個交易日後才能參與共振（`government-force-proxy.md` §4）
4. 校準管線需納入官股方向命中率追蹤
